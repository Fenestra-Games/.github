# Fenestra Games

Foundry VTT modules and tools for game masters, plus browser games that work on desktop and mobile.

Everything here is made by a small crew for a home D&D campaign, so expect quirks, in-jokes, and the occasional sea monster.

## About

Fenestra Games is the home of the code behind [fenestra.gripe](https://fenestra.gripe), a campaign hub for a seafaring, sky-faring D&D 5e adventure. Our projects grow out of that world: ominous, magical, gritty, and a little bit nautical.

## Foundry VTT development

Modules, macros, and setup helpers built for Foundry VTT v14 and the dnd5e system. We favour modules that are generic and portable, with no hardcoded actors or world data, so they drop into any game.

- **[Critical Splash Screens](https://github.com/Thriceisalways/critical-splash-screen):** per-character image overlays and sounds for natural 20s, natural 1s, death saves, ability and skill checks, and death status, with a full configuration window.
- **Self-hosted server setup:** an installer and server manager that walks a GM through hosting their own Foundry server behind a Cloudflare Tunnel.
- **More on the way:** new modules are in development.

### Installing a module

Each module repository includes a manifest URL. In Foundry, open **Add-on Modules**, choose **Install Module**, and paste the manifest URL into the box at the bottom.

## Games

Browser games set in the Fenestra world, playable on desktop and mobile. Progress is saved to the cloud with an anonymous save code or Google sign-in, so you can pick up on any device.

- **The Nut Smokers (platformer):** a pixel art platformer starring the party. Each character plays differently and has a once-per-level signature move, and a global arcade-style leaderboard tracks the best runs.
- **Runara Quest (deck-builder):** a Slay the Spire style roguelike deck-builder with a daily seeded run and relaxed free runs. Currently in development.

Play at [fenestra.gripe](https://fenestra.gripe).
